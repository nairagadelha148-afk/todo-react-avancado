Durante o desenvolvimento do projeto foram utilizados:

useState — gerenciamento de estados
useContext / Context API — compartilhamento do estado das tarefas entre componentes
Custom Hook (useInput) — controle do campo de entrada
useMemo — memorização do resultado da filtragem
React.memo — memorização do componente de tarefa
Props — passagem de dados entre componentes
Eventos (onChange e onClick)
Array methods (map e filter)

Como executar o projeto localmente:
Pré-requisitos

É necessário ter o Node.js instalado no computador.

Para verificar se o Node.js está instalado, execute no terminal:

node -v
Instalação

Clone este repositório e acesse a pasta do projeto:

git clone URL_DO_REPOSITORIO
cd NOME_DO_PROJETO

Em seguida, instale as dependências:

npm install
Executando a aplicação

Após instalar as dependências, execute:

npm run dev

O Vite iniciará o servidor de desenvolvimento. No terminal será exibido o endereço local da aplicação, normalmente:

http://localhost:5173

Acesse o endereço no navegador para visualizar a aplicação.

Objetivo do projeto

O projeto foi desenvolvido para colocar em prática conceitos fundamentais do React, como gerenciamento de estado, Context API, Custom Hooks, Props, eventos, renderização de listas e técnicas de memoização.
